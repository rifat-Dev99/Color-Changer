# 🎨 Color Changer

A Random Hex Color Generator built with HTML, CSS, and JavaScript.

## 🚀 Features

- 🎲 Generate Random Hex Colors
- 📋 Copy Color Code
- 🎨 Live Background Color Change
- ⚡ One Click Generate

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
